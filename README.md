# mlt-ulf
MLT dependent ULF index

## Requirements
The wavelet transform is done by using a module called PyCWT. Installation instructions can be found in https://pycwt.readthedocs.io/

[numpy](https://numpy.org/)
[netCDF4](https://unidata.github.io/netcdf4-python/)
[pandas](https://pandas.pydata.org/)

Index from 1995 to 2023 in mlat range 65-70 [![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.15372450.svg)](https://doi.org/10.5281/zenodo.15372450)
